# Problem Description

## Context

Sewing shops handle custom garment orders that pass through multiple stages from customer intake to delivery. Without a structured system, order details, measurements, material usage, and production progress are hard to track consistently.

## Problem

The shop needs a centralized management system to organize:

- customer records
- order details and garment items
- work tickets and production stages
- due dates and priorities
- final completion and delivery tracking

## Scope

The system covers the full operational lifecycle:

1. customer registration
2. order and garment creation
3. ticket generation and production follow-up
4. completion and delivery recording
5. operational monitoring and reporting

## Intended Users

- front-desk staff (customer and order intake)
- production coordinators (ticket assignment and stage updates)
- managers/owners (monitoring, overdue tracking, and delivery closure)
